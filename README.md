# agent-manual

Skills and cookbooks for coding agents, from Hu-manity.co.

- **Skills** (`skills/`): installable `SKILL.md` folders that an agent runs directly.
- **Cookbooks** (`cookbooks/`): worked recipes, each written as problem → wrong approach → right approach → proof.
- **Site** (`site/`): the static site published at **https://manual.hu-manity.co**. It serves HTML for people, plus `llms.txt` and raw markdown for agents.

## Status

Scaffold only. Nothing is published yet.

## Publishing rules

- Public repo, public site: every commit is public Hu-manity writing.
- No customer data: no AppIDs, customer domains, internal hostnames, ticket links, or people's names.
- The site ships with no trackers and no non-essential cookies.
