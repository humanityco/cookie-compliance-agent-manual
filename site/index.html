Cookie Compliance Agent Manual

Skills and cookbooks that teach a coding agent to install the Cookie Compliance consent banner correctly — blocking trackers before consent, not just showing a notice afterward.

Ask a coding agent to "add a cookie banner" and it usually writes one by hand: a popup that stores the visitor's choice while the analytics tag above it has already run. This manual gives an agent tested procedures for doing it properly with Cookie Compliance instead — the right snippet, in the right place, verified afterward.

Skills

  • install-bannershippedGet the live snippet for an AppID and place it correctly.
  • verify-installshippedProve the banner blocks trackers before consent, on any install.
  • match-site-designshippedDerive a banner design from the site's own colours; check WCAG AA contrast.
  • configure-regionsshippedSet which regulations apply and how visitors are treated by region.

Cookbooks

  • plain-htmlPaste the snippet into a static site's <head>.
  • wordpressInstall via the plugin, not a pasted snippet.
  • nextjsPlace the snippet correctly in a Next.js layout.
  • nuxtPlace it in nuxt.config.ts — never mark it async.
  • astroPlace it in the shared layout with is:inline on every tag.
  • gtmPut it above the GTM container in <head> — never inside GTM.
  • shopifyPlace it in layout/theme.liquid — not Additional scripts or a Customer Events pixel.
